# 🕹️ Como Jogar
O objetivo é acertar a maior quantidade de sequências de cores, em um total de 15 fases. A seguir, a função de cada uma das teclas presentes no jogo.

|Tecla|Função|
|---|---|
| 1 | Cor Verde |
| 2 | Cor Vermelha |
| 3 | Cor Azul |
| 4 | Cor Amarela |
| S | Sair |
| C | Tente Novamente |
| SPACE | Iniciar o Jogo |
| ENTER | Continuar |
